# 🎂 Birthday DM Studio V4

A Chrome Extension for creating timed Instagram message drafts.

## Features
- Custom message text
- Automatic progress from 1% to 100%
- 62-second interval
- Start, Pause and Reset
- Chrome Side Panel

## Installation
1. Download the extension ZIP.
2. Extract the ZIP file.
3. Open `chrome://extensions`.
4. Enable Developer mode.
5. Click Load unpacked.
6. Select the extracted extension folder.

**Note:** This extension inserts drafts only. Users must manually send messages.
