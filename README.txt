AFK DM AUTOMATION V5 — INSTALLATION

1. Extract AFK-DM-Automation-V5.zip.
2. Open Google Chrome and visit chrome://extensions
3. Turn ON Developer mode.
4. If an older Birthday DM Studio / AFK DM Automation version is installed, remove it first.
5. Click Load unpacked.
6. Select the extracted AFK-DM-Automation-V5 folder (the folder containing manifest.json).
7. Open instagram.com, open the intended chat, and refresh the page.
8. Click the extension icon to open the side panel.
9. Enter your message and click Save text.
10. Click Start.

BEHAVIOUR
- Immediately replaces the message box content with "your text 1%".
- Every 50 seconds, replaces the message box with the next percentage (2% ... 100%).
- Sets the target Instagram tab zoom to 100% while running.
- Restores the tab's previous zoom on Pause, Reset, completion, or error.
- Start / Pause / Reset are available.
- It does NOT click Send or press Enter. You must manually review and send each draft.
- It pauses if the original Instagram tab/chat is no longer the active tab or its URL changes.

IMPORTANT
- Any unsent text already in the message box is erased when each timed update happens. Copy anything important before starting.
- Keep the same Instagram chat open and active.
- Instagram may change its interface; if the message box is not detected, refresh Instagram and try again.
- Use only with people who expect your messages and follow Instagram's rules.
