BIRTHDAY DM STUDIO V4 — INSTALLATION

1. Extract Birthday-DM-Studio-V4.zip.
2. Open Google Chrome and visit: chrome://extensions
3. Turn ON Developer mode.
4. If an older Birthday DM Studio version is installed, remove it first.
5. Click "Load unpacked".
6. Select the extracted folder named Birthday-DM-Studio-V4 (the folder containing manifest.json).
7. Open instagram.com, open the intended chat, and refresh the page.
8. Click the extension icon to open the side panel.
9. Type your custom message and click Save text.
10. Click Start.

BEHAVIOUR
- Inserts "your text 1%" immediately.
- Inserts the next percentage every 1 minute 2 seconds.
- Stops at 100%.
- Start / Pause / Reset are available.
- It only inserts drafts. It does NOT click Send or press Enter.
- You must manually review and send each message.

IMPORTANT
- Keep the Instagram chat tab active when each timed draft is due.
- The Instagram interface can change; if the message box is not detected, refresh Instagram and try again.
- If you type something else into the composer after a draft is inserted, the extension will not overwrite it. Clear the composer yourself before restarting.
- Use this only with people who expect to receive your messages and follow Instagram's rules.
