AFK mode · 50-second interval

Every 50 seconds, the extension replaces all text currently in the Instagram message box with the next percentage draft (1%–100%). Chrome zoom is set to 100% while running and restored when paused, reset, completed, or stopped by an error. It never clicks Send or presses Enter. You must review and send each message yourself.

Warning: any unsent text in the message box will be erased at each update. Keep the same Instagram chat open and active.
